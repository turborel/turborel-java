# Appendix D: Versions

[Contents](README.md)

The driver's version is the turborel release it is made for, the same
number as the server's, and the driver has no version scheme of its own.
This alpha is turborel-jdbc 0.0.0, made for turborel 0.0.0, and it speaks
turborel's native protocol, version 1, which grows by capabilities rather
than by new versions. While the version is 0.y.z, anything may change from
one build to the next. The repository's
[VERSIONING.md](../../VERSIONING.md) says how releases are published.
