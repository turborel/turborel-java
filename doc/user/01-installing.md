# Installing

[Contents](README.md)

This chapter will tell what the driver needs, Java 17 or later on Linux,
macOS or Windows, and how to add it to a program or a tool: its Maven
coordinates, `com.turborel:turborel-jdbc`, the jar, and its use on the
module path as `com.turborel.jdbc` or on the class path. It is not yet
written: the driver does not connect to a server in this alpha. It is
written in M7, when the JDBC driver can be loaded, and its coordinates
are kept as they are once the driver is published (VERSIONING.md).
