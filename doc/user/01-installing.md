# Installing

[Contents](README.md)

This chapter will tell what the driver needs, Java 17 or later on Linux,
macOS or Windows, and how a program takes `com.turborel:turborel-jdbc` in from
Maven Central. No package is published until every Turborel driver is
done; until then the driver is built from its source, as the
repository's
[README](https://github.com/turborel/turborel-java/blob/main/README.md)
says. The chapter is written with the standard API, at milestone M7, and
again when the packages are published.
