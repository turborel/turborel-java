# Connection Settings

[Contents](README.md)

This chapter will tell where a connection's settings come from: the URL,
the program's own properties, a service file, a password file and
TURBOREL_* environment variables; several servers and the role asked of
them; and TLS by mode. M5 builds them, and the chapter is written in M7.
Each setting is listed in [Appendix C](../appendix/c-settings.md).
