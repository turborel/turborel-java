# Connecting

[Contents](README.md)

This chapter will tell how a program connects to a turborel server: the
JDBC URL and `DriverManager`, users and the ways they are proved (trust,
password, certificate and SCRAM-SHA-256), TLS, Unix sockets and Windows
named pipes, timeouts, and closing a connection. M2 builds the
connection beneath it, and the chapter is written in M7, when its
examples run through JDBC.
